# TeamO Mart Marketplace Web App

PHP and MySQL marketplace coursework project for browsing products and services, managing seller listings, and completing a basic cart-to-delivery checkout flow.

## Live Demo

https://teammarto.xo.je/login.php

Note: Coursework demo for testing only. Please use test details and avoid entering real personal, payment, or password information.

## Overview

TeamO Mart is a database-driven marketplace web application built with PHP and MySQL. It supports account creation, login, product browsing, seller item management, cart state, delivery details, and category-based discovery.

## Key Features

- User sign up and login
- Duplicate email and username checks
- Password hashing with `password_hash`
- Login verification with `password_verify`
- PHP sessions for logged-in navigation
- Product and service browsing
- Product details pages
- Cart and checkout flow
- Delivery details capture
- Seller dashboard
- Upload, update, and delete marketplace items
- Image upload handling
- Category, subcategory, and search filtering
- MySQL database connection with PDO
